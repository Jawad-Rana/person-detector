# Person Detection System

Faster R-CNN (ResNet50-FPN) model fine-tuned to detect people. Upload an image and every person is marked with a bounding box.

- App: Streamlit (`app.py`)
- Model: `rcnn_model.pth`, downloaded automatically from Google Drive on first run
- Dataset: https://drive.google.com/drive/folders/10d_w51uRXeIsoWih5UTTd6MxENb0CRpr
